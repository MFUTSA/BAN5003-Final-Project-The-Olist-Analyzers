## 1. Project Summary

This project examines the differences between estimated and actual delivery dates using Olist e-commerce data. Our goal is to improve delivery estimates while maintaining a low percentage of late deliveries.

We compare Linear Regression and Random Forest models, evaluate delivery buffers, and examine differences across geographic locations, months, and single-item and multi-item orders.

Our primary objectives are:

- Achieve a median estimated-to-actual delivery ratio between 1.00 and 1.25.
- Maintain a late delivery rate below 6.9%.

### Analysis Process

- Load the data using the saved SQL queries.
- Prepare the modeling variables and handle missing values.
- Split the modeling data into training (60%), validation (20%), and testing (20%) sets.
- Remove extreme delivery estimation errors from the training data.
- Compare Linear Regression and Random Forest models.
- Evaluate delivery buffers using validation results.
- Report final model performance using the test dataset.
- Examine geographic, monthly, and multi-item delivery patterns.
- Generate and save visualizations.

A random seed of 42 is used to support reproducibility.

## 5. Results and Output Files

All analytical results and visualizations are saved in the `outputs/` folder.

### Model Results

| Metric | Linear Regression | Random Forest |
|---|---:|---:|
| Validation MAE (days) | 5.37 | 5.21 |
| Validation RMSE (days) | 8.69 | 8.56 |
| Validation R-squared | 0.231 | 0.254 |

Random Forest was selected based on its lower validation MAE.

### Final Delivery Performance

| Metric | Original Olist | Random Forest with 10-Day Buffer |
|---|---:|---:|
| Median delivery ratio | 2.30 | 2.21 |
| Late delivery rate | 6.75% | 6.00% |
| MAE (days) | 13.25 | 11.90 |

The Random Forest model with a 10-day buffer improved delivery estimation accuracy and met the late delivery target. However, the median delivery ratio remained above the target range.

Additional model adjustments and validation are recommended before implementation.

### Limitations

- The predictive models focus on single-item orders.
- Multi-item orders were examined separately but were not used to validate the predictive models.
- Customer ZIP code was excluded from modeling due to its high number of unique values.
- Monthly delivery patterns do not establish the effects of specific holidays.
- The test dataset was examined during model development. Additional independent validation is recommended.
- The final model did not achieve both original project objectives.
